# 📝 轻量 Todo 工具 — 使用说明

## 什么是 LightTodo

一款基于 **Python + PyWebView** 的桌面待办事项工具，采用 Apple 风格 UI 设计（HTML/CSS），提供简洁高效的日常任务管理体验：

- **极简交互**：原生窗口 + 内置 Web 页面，Apple 风格圆角卡片、柔和阴影
- **数据本地化**：所有任务和历史记录存储为本地 JSON 文件（`todo_data.json`），无需数据库
- **无边框置顶**：frameless 窗口始终置顶，可拖拽移动，适合桌面常驻使用

---

## 功能一览

| 功能 | 说明 |
|------|------|
| ✅ **任务管理** | 添加、完成/取消完成、删除任务，已完成任务自动排序到底部 |
| 📋 **历史归档** | 清除已完成任务时自动归档到历史记录，附带归档时间戳 |
| 🔄 **历史恢复** | 历史记录支持逐条恢复或一键全部恢复 |
| ✏️ **任务编辑** | 双击/点击任务文本可弹出详情弹窗，修改任务内容 |
| ⚙️ **开机自启动** | 设置页面开关控制是否随系统启动（写入 Windows 注册表 Run 键） |
| 📌 **桌面置顶** | 窗口始终置顶，眼不见心不乱 |
| 🪟 **无边框拖拽** | 标题栏区域支持拖拽移动窗口，右上角最小化/关闭按钮 |

## 准备工作

| 工具/文件 | 用途 |
|-----------|------|
| [Python 3.8+](https://www.python.org/downloads/) | 提供 Python 运行环境 |
| `requirements.txt` | Python 依赖清单 |
| `todo_app.py` | 主程序脚本 |
| `build.bat` | 打包为独立 exe 的构建脚本（可选） |

## 安装与运行

### 方式一：直接运行（Python 环境）

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 运行
python todo_app.py
```

### 方式二：打包为独立 exe

双击 `build.bat`，脚本会自动执行 PyInstaller 打包，生成独立的 `.exe` 文件，无需 Python 环境即可运行。

## 使用说明

### 主界面

- 窗口出现在屏幕**右上角**（310×420 像素），始终置顶
- **任务列表区**：卡片式展示，已完成任务带删除线并排到列表末尾
- **输入栏**：底部输入框输入任务内容，按 Enter 或点击 `+` 添加
- **底部操作栏**：
  - `清空已完成` — 将所有已完成任务归档到历史记录
  - `历史记录` — 打开历史记录弹窗，查看/恢复/清空历史

### 任务操作

| 操作 | 方式 |
|------|------|
| 标记完成/取消 | 点击任务左侧圆形复选框 |
| 删除任务 | 鼠标悬停任务卡片，点击右侧 `✕` 按钮 |
| 查看/编辑详情 | 点击任务文字弹出详情弹窗，修改后点「保存」 |

### 设置

点击标题栏 ⚙ 图标打开设置弹窗：

- **开机自启动**：开关控制是否在系统启动时自动运行（写入 `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`）

### 历史记录

- 点击底部「历史记录」打开弹窗
- 按归档时间分组展示，支持逐条恢复或一键全部恢复
- 可清空所有历史记录（有二次确认）

## 数据存储

所有数据存储在脚本同级目录的 `todo_data.json` 中：

```json
{
  "tasks": [
    { "text": "完成周报", "done": false }
  ],
  "history": [
    { "text": "旧任务", "done": true, "archived_at": "2026-01-01 12:00:00" }
  ],
  "settings": {
    "auto_start": false
  }
}
```

## 常见问题

**Q：窗口无法拖拽移动？**

A：拖拽仅支持标题栏区域（"📝 待办事项" 文字所在的行），按钮区域不可拖拽。

**Q：为什么开机自启动无效？**

A：请以**管理员权限**运行一次程序后再开启自启动开关。部分安全软件可能会拦截注册表写入。

**Q：如何备份我的任务数据？**

A：复制 `todo_data.json` 文件即可。将该文件放到新环境中的 `todo_app.py` 同级目录即可恢复所有数据。
