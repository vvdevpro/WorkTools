# Todo App v3.2 更新说明

## 新增功能

### 1. 📅 任务创建时间显示
- ✅ 创建任务时自动记录创建日期和时间
- ✅ 在任务卡片右侧显示创建日期（格式：YYYY-MM-DD）
- ✅ 显示该任务距今已经过多少天

### 2. 🔴 红字提醒阈值设置
- ✅ 在**设置**面板中新增"红字提醒天数"滑块
- ✅ 可以自定义任务超过多少天后用红字显示（范围1-30天，默认3天）
- ✅ 修改设置后即时更新显示效果
- ✅ 设置自动保存，下次启动应用会保持设置

### 3. 🖱️ 任务拖拽排序
- ✅ 在任务列表中直接拖拽**未完成**的任务可调整顺序
- ✅ **已完成的任务无法拖拽**（防止误操作）
- ✅ 鼠标悬停在可拖拽任务上会显示"可移动"光标提示
- ✅ 拖拽时任务会变半透明显示拖拽状态
- ✅ 拖拽完成后自动保存新的任务顺序

### 4. 📏 窗口大小调整与保存
- ✅ 窗口右下角有调整大小的把手（灰色三角形）
- ✅ 在把手上拖拽可以调整窗口宽度和高度
- ✅ 窗口大小自动保存到配置文件
- ✅ 下次启动应用时会恢复上次调整的窗口大小
- ✅ 最小窗口尺寸：宽度 280px，高度 300px

## 技术实现细节

### 后端改进
- 数据结构中新增字段：
  - `created_at`: 任务创建时间戳
  - `red_days`: 红字提醒天数阈值（默认3天）
  - `window_width`/`window_height`: 保存的窗口尺寸

- 新增方法：
  - `reorder_tasks()`: 支持任务重新排序
  - `set_window_size()`: 调整和保存窗口大小

### 前端改进
- 新增函数：
  - `getDaysDiff()`: 计算任务距今天数
  - `updateRedDays()`: 更新红字阈值
  - `dragStart/dragOver/dragDrop/dragEnd()`: 拖拽处理函数

- UI 增强：
  - 任务卡片支持 HTML5 拖拽
  - 设置面板新增滑块控制器
  - 右下角添加窗口大小调整把手

## 使用建议

1. **创建任务时设置提醒天数**：
   - 进入设置，调整滑块至合适的天数
   - 例如：设置为5天，则5天未完成的任务会显示红字提醒

2. **整理任务顺序**：
   - 按住任务卡片拖拽可调整位置
   - 鼠标会变成移动光标提示可拖拽

3. **个性化窗口大小**：
   - 拖拽右下角的三角形调整窗口大小
   - 默认大小为 310×420，可根据需要调整
   - 下次启动会保持你调整的大小

## 数据结构示例

```json
{
  "settings": {
    "auto_start": false,
    "red_days": 3,
    "window_width": 310,
    "window_height": 420
  },
  "tasks": [
    {
      "text": "完成项目报告",
      "done": false,
      "created_at": "2026-06-11 08:30:45"
    }
  ],
  "history": []
}
```
